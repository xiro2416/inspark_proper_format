ZipVoice reference and evaluation code

The reference model and the UTMOS/ECAPA-WavLM evaluation implementations retain
code from k2-fsa/ZipVoice. Evaluation files were recovered from upstream commit
2f7326fbfe999a3ad179e3f1af82a424d4a62819; detailed file provenance is recorded in
reports/sm89/zipvoice/a1007. The upstream Apache-2.0 license is included as
LICENSE.ZipVoice. Existing file headers and the SpeechMOS attribution in
utmos.py are retained. Model checkpoints are separate private download assets.
